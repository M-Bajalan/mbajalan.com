# mbajalan.com

Source for my personal site, mbajalan.com. It's a single static page — hand-written HTML and CSS, no build step, no dependencies, no framework.

To preview locally, run `python -m http.server` from the repo root and open http://localhost:8000.

Deploys to GitHub Pages from `main`. The custom domain is set by the `CNAME` file, so don't remove or rename it.
